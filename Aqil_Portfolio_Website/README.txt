AQIL — ELECTRICAL ENGINEERING PORTFOLIO

How to use:
1. Keep the folder structure unchanged.
2. Double-click index.html to open the website in Chrome/Edge.
3. To edit text, open index.html with Notepad or VS Code and search for the text you want to change.
4. To add/replace photos, put the image inside assets/ and change the filename in index.html.
5. No server, framework, or installation is required.
